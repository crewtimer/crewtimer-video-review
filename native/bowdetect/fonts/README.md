# Synthetic OCR training fonts

These fonts are vendored for reproducible synthetic OCR training locally and in
Google Colab.

`RobotoCondensed-Bold.ttf` is from the official
[googlefonts/roboto](https://github.com/googlefonts/roboto) repository and is
distributed under the Apache License 2.0 included in `LICENSE.txt`.

`LiberationSans-Regular.ttf` (Liberation 2.00.1) is metric-compatible with
Arial. Training squeezes it to 85-90% width to match the regular-weight narrow
digits on many head-race bow cards. It is distributed under the SIL Open Font
License 1.1 included in `LICENSE-LiberationSans.txt`.
